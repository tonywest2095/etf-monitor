# ETF 低吸高抛日报

每个交易日午盘（11:45）和收盘（15:45）自动跑一次，生成一页手机可读的 HTML 报告：
哪些 ETF 超卖可以低吸、哪些放量启动可以跟随、哪些该止盈，以及全池 RSI、均线、MACD、回撤一览。

> 重要说明：本项目在开发环境里无法访问行情接口，所有流程是用**模拟行情**跑通和测试的。
> 三个数据源的解析器按接口格式写好并有单元测试，但**第一次真实联网运行请你盯一下**（见"首次运行检查"）。

## 1. 三分钟跑起来

```bash
pip install -r requirements.txt
python -m etf_monitor --demo            # 不联网，看版面：docs/index.html
python -m etf_monitor                   # 联网，真实行情（30 只）
python -m etf_monitor --size 10         # 只看 10 只核心档；20 同理
python -m pytest -q                     # 单元测试
```

非交易日或行情没更新时程序会打印 `[skip]` 并退出，不覆盖上一期报告；加 `--force` 可强制生成。

## 2. 每天自动运行（二选一）

### 方案 A：GitHub Actions（推荐，免费，不用开电脑）

1. 新建一个 GitHub 仓库，把本目录全部推上去（含 `.github/workflows/etf-monitor.yml`）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/docs`。
3. 仓库 Actions 页面手动点一次 `ETF 日报` → Run workflow（force 填 yes），确认能出报告。
4. 之后工作日 11:45、15:45（北京时间）自动运行，报告地址 `https://<用户名>.github.io/<仓库名>/`，
   历史报告在 `/archive/`。
5. 可选：Settings → Secrets 里加 `FEISHU_WEBHOOK`（飞书群自定义机器人地址），每次跑完推送一条摘要。

注意：GitHub 的定时任务高峰期会晚 5~20 分钟；Actions 服务器在海外，东财接口偶尔拒绝海外访问，
程序会自动换腾讯、新浪。想在收盘前下单，可打开 workflow 里 14:50 尾盘那一行。

### 方案 B：自己的电脑 / 服务器

```cron
# crontab -e （服务器时区为北京时间）
45 11 * * 1-5 cd /path/etf-monitor && python -m etf_monitor >> run.log 2>&1
45 15 * * 1-5 cd /path/etf-monitor && python -m etf_monitor >> run.log 2>&1
```

Windows 用"任务计划程序"建两个每日任务，程序填 `python`，参数 `-m etf_monitor`，起始于本目录。

## 3. 首次运行检查

- 终端摘要里有没有 `[error]`；报告顶部有没有"数据提醒"。
- 随便挑 2 只，和行情软件对一下：RSI14（参数 14）、MACD（12,26,9）、MA5。差 0.1 以内正常。
- 历史高点用的是**前复权**价，和软件里"前复权"K 线的最高点对比。
- 跑一次 `python -m etf_monitor.pool_audit`，确认每个赛道留的是规模和成交最大的那只。

## 5. 信号定义

| 信号 | 条件 | 报告给出 |
|---|---|---|
| 左侧低吸 | RSI14 < 30 / 20 / 10 三档 | 是否已止跌、分档仓位、反抽目标（MA20）、认错条件、历史同类信号 10 日表现 |
| 右侧启动 | MA3/5/7 连续 ≥2 天同步向上，MA3>MA5>MA7，量比 ≥1.2，收盘在 MA7 上；只在启动 3 天内提示；RSI≥70 或乖离>8% 不追 | 仓位、止损（2×ATR）、吊灯止盈线 |
| 高抛提示 | RSI ≥70 / ≥80；涨后三线同步向下；0 轴上方死叉；跌破吊灯止盈线 | 原因与止盈线 |
| 观察 | RSI 30~35；三线向上待放量；低位金叉初期；趋势延续中 | 折叠列表 |

仓位规则：单笔最多亏总资金 1%，单只不超过 20%；年线下方减半，高波动再减半。全部可在 `config.py` 调。

## 6. 已知局限

- 午盘 / 尾盘的量比按"上午占全天 56%、14:50 前占 93%"折算，是经验值。
- 收盘信号只能次日执行，存在隔夜跳空；这是日线策略的固有问题。
- 跨境 ETF 的溢价率没有接入，报告只做文字提醒，下单前自己看一眼。
- 机械信号本身期望收益有限，报告定位是"候选名单 + 纪律"，最后一步人工复核不能省。
- 本工具只做信息整理，不构成投资建议。

## 7. 模拟盘（docs/sim.html）

日报每次运行后，模拟盘用同一份行情自动下单、记账，看板地址 `https://<用户名>.github.io/etf-monitor/sim.html`。

- 初始资金 10 万，单只最多 50%（`config.py` 的「模拟盘」一节可改）。
- 收盘那次按日报信号决策，订单在下一交易日开盘价成交；午盘那次补记成交并按午盘价更新市值。
- 含滑点 0.05% + 手续费万3；开盘涨停买不进、跌停卖不出。
- 看板：总资产 / 收益 / 跑赢沪深300 / 回撤 / 仓位、净值曲线（对比沪深300和池子等权持有）、持仓、待成交、成交记录、按信号分组的胜率与盈亏比。
- 同一套规则的近 2 年历史回测附在页面底部，每天收盘重算。
- 账户数据在 `docs/sim/state.json`；想重新开户，删掉 `docs/sim/` 目录即可，下次收盘自动重开。
